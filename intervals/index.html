    Interval Timer

    A repeating timer for activities that run in rounds: speed debates, station rotations, one-minute presentations, timed quiz questions. Set one interval length and press start. When you move to the next interval, any seconds left over are added to it and any overrun is taken off it, so the whole activity still finishes on time. A small total keeps track of how long the activity has been running.

    How to use it

    1. Set the interval length, for example 0 minutes 30 seconds. It is remembered for next time.
    2. Press Start. The interval counts down in large digits, with the total elapsed time above it.
    3. Press the big Next interval button, the spacebar or N when a round ends early or late. Press Reset or R to start the activity again.

    Frequently asked questions

    What happens if an interval runs over?

    The countdown continues past zero and shows the overrun with a minus sign. When you press Next interval, that overrun is subtracted from the new interval, so a 30-second round that ran 5 seconds late gives the next round 25 seconds.

    What happens if I move on early?

    The seconds left are added to the next interval. Finish a 30-second round with 10 seconds spare and the next round gets 40 seconds. The total elapsed time keeps counting either way.

    How is this different from the classroom timer?

    The classroom timer counts down once and stops. The interval timer repeats the same length as many times as you need and keeps a running total, which suits rotations and rounds.
