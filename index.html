    Random Student Picker

    Classroom Picker is a free random name picker built for the classroom projector. Paste your class list once and it is saved on this device, so tomorrow it is already there. Press the spacebar and a name appears in letters big enough to read from the back row. Every student is picked once before anyone is picked again, so the class can see it is fair.

    How to use it

    1. Paste your class list, one name per line or straight from a spreadsheet, and press Save class.
    2. Press Pick someone or tap the spacebar. The chosen name fills the screen.
    3. Press F for presenter mode, a full-screen view with nothing but the name. Press Esc to leave it.

    Frequently asked questions

    Is the random student picker really free?

    Yes. There is no account, no paywall and nothing to install. The whole tool is a single web page that works on any laptop, Chromebook or interactive whiteboard.

    Does it avoid picking the same student twice?

    Yes. Every student is picked once before the list resets, and the bar under the stage shows how many are still to go. Press Start over or R to begin a new round.

    Where is my class list stored?

    In your browser's local storage on this device only. Nothing is uploaded, so there is no server holding pupil names. Clearing your browser data removes the list.

    Can I use it as a random name generator for anything else?

    Of course. Any list of names works: raffles, chore rotas, choosing who reads next, or picking a team captain. It is a general randomiser that happens to be tuned for teachers.
